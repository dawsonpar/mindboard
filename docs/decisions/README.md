# Decision records

Short, technical records of the architectural and product decisions behind
MindBoard. One file per decision, named `NNNN-kebab-title.md`.

## Format

Each record has: Date, Status (Proposed | Accepted | Superseded), Context,
Decision, Consequences, Alternatives considered.

## Scope and privacy

**This repository is public.** Keep every record abstract and technical:

- Document the technical decision and its trade-offs, and nothing else.
- Do not include employer, client, or internal context; personal details;
  private timelines; or strategic or competitive rationale.
- Use neutral, fictional sample data in any examples (never real card content).
- If a decision has sensitive "why" behind it, keep that reasoning in a private
  channel (the MindBoard card for the work, or local notes), not here. The
  record can simply state the technical decision.
